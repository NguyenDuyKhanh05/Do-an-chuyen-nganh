# 🚀 Ứng Dụng Web Mẫu Trên Môi Trường Ảo Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)]
## 📖 Giới thiệu đề tài
Đề tài: **Phát triển phần mềm trên môi trường máy ảo với Codespaces**.  
Mục tiêu: Xây dựng quy trình phát triển "Zero-Setup", giúp sinh viên/lập trình viên khởi động toàn bộ môi trường làm việc chỉ với 1 cú click chuột mà không cần cài đặt Node.js hay cấu hình phức tạp trên máy tính cá nhân.

---

## ⚡ Hướng dẫn sử dụng nhanh (Zero-Setup)
1. Bấm vào nút **Open in GitHub Codespaces** ở đầu trang (hoặc nút **Code** -> chọn tab **Codespaces** -> **Create codespace on main**).
2. Chờ GitHub khởi tạo container (khoảng 1 - 2 phút lần đầu).
3. Trong Terminal của Codespaces, gõ lệnh:
   ```bash
   npm run dev
